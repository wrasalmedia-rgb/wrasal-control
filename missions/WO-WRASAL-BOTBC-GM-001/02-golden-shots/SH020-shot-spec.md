# SH020 — Shot Specification (Golden Shot) — FIRST SUPERNATURAL VISUAL

**ID:** SH020  
**Duration:** 3s  
**Timecode:** 00:57–01:00  
**Act:** III — Jamaican Gothic Horror (entrance)  
**Time Period:** 2026  
**Required Content:** Red thread retracts impossibly  
**Genre State Before:** Red revealed but not yet moving (SH019); uncanny dread but still photographable  
**Genre State After:** "That cannot happen" — supernatural is now visual, not only acoustic

**This shot is the most technically and ethically important shot in the trailer.** It must be photographic, comprehensible, and brief enough to be witnessed rather than explained.

---

## Narrative Intention

The red thread — revealed beneath older repairs in SH019 — **moves without visible physical intervention**. It retracts into the fabric (~1–2 cm in ~1.5s) with a smooth, unthreadlike intentionality. The audience must *see* impossibility, not trick. This is the trailer's epistemological rupture: reality's model fails.

The shot is not a scare; it is a fact. Horror will follow (SH021–030) from what this fact does to understanding.

**Primary Question Planted:** *What moved that? — and why did it answer?*

## Camera Setup

| Parameter | Specification | Rationale |
|-----------|---------------|-----------|
| **Camera** | Alexa Mini LF on locked sticks — no micro-jitter | Witness must be absolutely stable so movement is attributable to thread, not camera |
| **Framing** | Extreme close-up — hem occupies full width of 2.39:1 frame; red thread centered horizontally; hands frame edges but do not obscure. Red thread must be legible at phone size. | Thread is protagonist; hands are corroborating witnesses that they are not pulling |
| **Angle** | 90° overhead or 30° raking — overhead preferred to see both thread surfaces and hands simultaneously. | Overhead proves hands not pulling; raking emphasizes thread texture |
| **Movement** | None — absolutely locked. Any movement destroys evidentiary credibility. | Doctrine: Camera as Witness, Not Magician |
| **Focus** | Locked on thread plane; deep enough to hold hem + hands in focus. Use focus chart; tape measure. | No rack — focus shift would look like effect |

**Coverage Plan (PROPOSED):**  
- A-camera: Overhead ECU (primary — this spec).  
- B-camera (secondary, for editorial safety): 45° raking ECU side-close, same action, same timing. Cut to B-camera is **not** in trailer (single angle preserves witness credibility) but provides continuity verification.

## Lens and Framing

- **Lens (PROPOSED):** 60mm macro or 100mm macro (Leica R 60mm Macro or Cooke Panchro 60mm) on LF at 1:1 magnification. Thread ~2mm thick must occupy ~1.5–2% of frame width on LF 4.5K sensor — resolvable after 2.39 crop.
- **Aperture (PROPOSED):** T5.6–T8.0 — deep depth to hold entire thread travel (1.5cm) in focus without rack. Requires more light; acceptable.
- **ND/ISO:** Adjust to maintain T5.6–T8 without compromising sensitivity. Use ISO 800; ND as needed.
- **Monitor:** On-set 4K scope monitor to confirm thread travel legible at 2.39 extract.

## Lighting

- **Style:** Same 2026 interior as SH018–019 — neutral daylight, not warm 1980s. But for SH020, a **slight luminance increase** on thread is allowed (PROPOSED: small hard accent) to make red legible without looking theatrical. Must be motivated as window light.
- **Key (PROPOSED):** Soft window daylight camera-left, 45°, 5600K — rakes hem to create thread shadow that confirms thread is *on* fabric surface, not composited.
- **Fill:** White bounce camera-right — ratio 1.5:1; neutral.
- **Thread Accent:** Small 1×2 LED (Aputure MC) with 20° grid, 5200K, 15% level — aimed solely at thread path to make waxed surface catch. Flagged off hands/shirt mass so only thread gets specular.
- **Shadow Check:** Thread must cast a tiny, physically correct shadow onto fabric before retracting (proves practical location). Shadow moves with thread.
- **Color:** Neutral — red must read as blood/ceremonial, not orange. Test grade: waxed red thread (Proposed: Fil au Chinois waxed linen #1143) under 5600K + 1/4 CTO variant.

## Practical Execution Method (Two Options — Director Chooses)

### Option A — Practical Wire Pull (Preferred for Witness Credibility)

1. Thread tail is waxed red thread with 0.1mm monofilament attached to tip *beneath fabric* (through stitch hole).
2. Under-table technician pulls monofilament smoothly during take (rehearsed timing 1.2s).
3. Monofilament is invisible at T4: waxed thread casts shadow; monofil is hidden beneath fabric plane.
4. Hands hold shirt taut over rigged surface (false table edge) so no visible pull.
5. Multiple takes: 12+ pulls for timing selection.
6. Advantage: no VFX; physically plausible to skeptical viewer.

### Option B — VFX Clean (Backup)

1. Shoot SH020 as static plate — red thread present, unmoving.
2. Shoot thread-retraction as VFX animation with CG thread + shadow, composited onto plate.
3. Track fabric weave for convincing integration; preserve blue/white immobility.
4. QC: Witness must not detect composite edge; test on 4K scope.
5. Disadvantage: Witness must note VFX provenance; still valid if execution is invisible, but practical is preferred per "Reality First."

**Recommended:** Test both; select based on invisible evidence. Record method chosen in evidence ledger.
