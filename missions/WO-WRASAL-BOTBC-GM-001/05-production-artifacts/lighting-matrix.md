# Lighting & Color Matrix

**Mission:** WO-WRASAL-BOTBC-GM-001  
**Date:** 2026-10-23  
**Doctrine:** Reality First — All lighting motivated; no unmotivated horror color

---

## 1. Lighting Philosophy

The trailer's genre progression is carried partly by light **without announcing itself**. Warm communal light → warm forensic domestic → neutral hush → neutral inquiry → subliminally thinner light on recontextualization. No green/purple horror palette. No unmotivated god rays. Every source is a window, practical, or bounce justified as architectural.

### 2.1 Motivation Map

| Source | What It Is | Color | Where It Appears | Notes |

| **Bathroom practical** | Vanity sconce / ceiling | 3000K warm | SH022 | Motivates empty bathroom's warmth against throat clearing's uncanny |
| **Hard accent for thread** | 1×2 LED with 20° grid (Aputure MC or Litepanel 1×1 focused) | 5200K | SH013, SH014, SH018–020 macro hems | Rakes thread texture; flagged off faces; creates thread shadow; motivation: gap in curtain |
| **Bounce** | White wall / unbleached muslin / 4×4 bounce | Matches key, slightly warmer if muslin | All interiors | Fill; softens without denying shadows needed for later uncanny |

## 5. Verification & Stewardship

- Lighting must not create unmotivated horror color (QC: no gelled green/purple in any house shot).
- SH031 subliminal change (fill -0.5 stop + 1/8 CTB) must be ≤0.5 stop difference from SH007 — validator checks reported light levels (see blocking matrix addendum).
- Macro hard accent always motivated as curtain gap — on-set still must show curtain/practical in frame or just off to justify accent direction.
